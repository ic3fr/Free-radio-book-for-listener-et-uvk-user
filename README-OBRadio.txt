==============================================================
En - ENGLISH
==============================================================

What is in the book

The book is a single PDF file, in two sizes:
- FrOpenBookRadio-V7.0.PDF: standard version (full-quality images, for printing)
- FrOpenBookRadioLite-V7.0.PDF: same content, smaller file (screen, phone)

The file has three parts. Each one has its own title page, its own page numbering (starting again at 1), its own version at the bottom of the page and its own back cover:
1. Book: introduction, chapters 1 to 9, chapter 10 DIY (sheets DIY01 to DIY19), section R Regulations and transmitting (sheets R01 and R02), credits, notes to the future AI. The book can be read on its own.
2. UV-K1 / UV-K5 V3 annex: sheets K01 to K23. It refers to the book for the basics.
3. Manuals annex: the original manuals of the Sonic, GOGUFW, Apex and Falcon firmwares (M01 to M04), translated into French.

A fourth part, the UV-K10 Pro annex, will be added to the set if open-source firmwares are released for this radio.

Splitting the book

You can split it. The first and last PDF pages of each part are in the table "Les parties de ce fichier" (the parts of this file), in the book's contents. In your PDF reader, choose "Print", the "PDF" printer, then these pages. In a separated part, links to the other parts no longer work, but the sheet numbers are still written.

Separate files
- {Lg}BookUVK1-K5V3-Overlay-V7.0.PDF: overlay apps booklet
- {Lg}BookUVK1-K5V3-AltFw-V7.0.PDF: alternative firmwares booklet
- EN-listofchange-OBRadio.pdf: list of changes (in English)
- README-OBRadio.txt: this file

File names
- {Lg} = the language: Fr, En, Es, De, Pl, It, Pt, Nl, Cz, Ua, Ru, Cn, Jp (first letter upper case, second lower case).
- V7.0 = the version; it follows the Fusion firmware by F4HWN (V7.0 for Fusion 7.0). No date in the name.
- The book is in French. The booklets exist at least in French, English and Spanish (13 languages so far).
- Radios covered: UV-K1 and UV-K5 V3 only, not the UV-K5 V1.
